# Climate Risk Assessment for Kazakhstan

An adaptation of the [CLIMAAX CRA Handbook](https://handbook.climaax.eu/) for Kazakhstan, replacing European-specific datasets with globally available alternatives while maintaining the original scientific methodology.

<img src="https://raw.githubusercontent.com/CLIMAAX/crabook/main/crabook/logo.png" height="100" />

## About

This repository provides Jupyter notebook workflows for climate risk assessment across multiple hazards relevant to Kazakhstan. The risk assessment follows the **Risk = Hazard × Exposure × Vulnerability** framework from the original CLIMAAX project, adapted for Kazakhstan's administrative structure (oblasts and districts).

## Setup

```bash
# Clone the repository
git clone https://github.com/Zeveow11/climaax-kazakhstan.git
cd climaax-kazakhstan

# Set up the Python environment
conda create -n crabook-kz python=3.11 pip
conda activate crabook-kz
pip install -r requirements.txt
```
